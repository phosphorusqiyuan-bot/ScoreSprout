# Salamander Grand Piano

Recorded by Alexander Holm. Piano recordings, not synthesized waveforms.
Original library: https://github.com/sfzinstruments/SalamanderGrandPiano
License: Creative Commons Attribution 3.0 Unported (CC BY 3.0)
https://creativecommons.org/licenses/by/3.0/

Unmodified MP3 distribution: https://github.com/Tonejs/audio/tree/master/salamander
Downloaded from https://tonejs.github.io/audio/salamander/ on 2026-10-23.
This application bundles 30 minor-third-spaced samples A0–C8. Playback transposes
the nearest recording, applies velocity gain and a short note-off release.
The recordings are not a full multi-velocity SFZ implementation.
See manifest.json for file sizes and SHA-256 hashes.
